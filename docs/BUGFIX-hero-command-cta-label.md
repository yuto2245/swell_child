# バグ修正レポート: トップ Command CTA のラベル表示不具合

**日付**: 2026-05-28  
**ブランチ**: main（修正時点）  
**報告者**: Grok 4.3 (xAI)  
**関連ブランチ**: feature/top-command-cta

---

## 1. 現象（What was observed）

フロントページのヒーローセクションにある「Knowledge API 導線」のコマンド風 CTA（`.hero-command`）に、**視覚的なラベル（説明テキスト）が存在しなかった**。

- ユーザーが見えるのは `curl https://...` というコード文字列だけ
- 実際には `aria-label="APIドキュメントでコマンド実行例を見る"` のみで、スクリーンリーダー以外には何の説明もない
- 背景が `rgba(255, 255, 255, 0.64)` の半透明ガラスモーフィズムのため、存在感が薄く「何のための要素か」が一目で分かりにくい状態だった

結果として「CTAラベルの表示がおかしい」と感じられる UI になっていた。

---

## 2. 根本原因（Root Cause）

`feature/top-command-cta` 機能の実装時に、以下の設計判断ミスが発生した：

1. **視覚ラベルの完全欠落**  
   コマンド文字列自体を「ラベル代わり」にしてしまい、別途 `<p class="hero-command-label">` などの説明要素を追加しなかった。

2. **aria-label のみ依存**  
   アクセシビリティ対応として `aria-label` は正しく付与されていたが、**視覚ユーザー向けのラベルを同時に用意していなかった**。

3. **背景不透明度の優先**  
   デザインの美しさ（ガラスモーフィズム）を優先し `background: rgba(255, 255, 255, 0.64)` を採用した結果、ヒーロー背景 + オーバーレイとの組み合わせで CTA の視認性・存在感が低下した。

要するに「**機能としてコマンドをトップに置く**」という目的は達成したものの、「**それが何のための CTA なのかを視覚的に伝える**」というラベリング工程をスキップしていた。

---

## 3. 影響範囲

- フロントページ（`front-page.php`）のヒーローセクションのみ
- 特にデスクトップでの初回訪問ユーザーに対して「Knowledge API が試せる」という意図が伝わりにくい
- モバイルでも同様（コマンド文字列が長く、エリプシスで切れる可能性もあり）

---

## 4. 修正内容

### 変更ファイル

1. `front-page.php`
   - `.hero-command` の直前に可視ラベルを追加:
     ```html
     <p class="hero-command-label">Knowledge API をコマンドで試す</p>
     ```

2. `style.css`
   - 新規ルール `.hero-command-label` を追加（既存のヒーローコマンド群の直後）:
     ```css
     .hero-command-label {
       font-size: var(--text-xs);
       font-weight: 600;
       letter-spacing: 0.08em;
       text-transform: uppercase;
       color: var(--color-text-muted);
       margin: 0 0 6px;
       opacity: 0.85;
     }
     ```

### 修正のポイント

- 既存のデザインシステム（`--text-xs`、`--color-text-muted`）に完全に準拠
- `text-transform: uppercase` + `letter-spacing` でマイクロコピーらしい控えめな存在感
- `margin-bottom: 6px` でコマンドピルとの間隔を最適化

---

## 5. 予防策・学び

- 重要な CTA を実装する際は、**「aria-label だけでは不十分」**であることを常に意識する。
- 特に「コマンド風 UI」のような非標準的な表現を使う場合は、**必ず視覚的なラベルをペアで用意**する。
- 背景不透明度を決める前に、実際のヒーロー背景とのコントラスト検証を必ず行う。
- 今回のケースは「機能開発に集中しすぎて、ラベリングという情報設計工程を後回しにした」典型例。
